# HASH — Miner Showcase

A standalone responsive landing page comparing two mining machines. All names and financial figures are clearly marked sample content.

## Preview

Run `python3 -m http.server 4173 --directory dist` from this folder and open http://localhost:4173.

## Customize

Edit `dist/index.html`. Product data is in the `miners` array. Replace the conceptual SVG illustrations with real product photos and connect the inquiry buttons to your sales destination.

Monthly revenue is scaled by uptime. Electricity expense uses a 30-day month and the same uptime. Annual ROI is annualized net operating profit divided by hardware price; fees, taxes, maintenance, and changes in mining conditions are excluded.

## GitHub

This project has its own Git repository, independent of the enclosing workspace. Create a new GitHub repository and add its URL as this project's origin. Never reuse the Equalizer remote.
